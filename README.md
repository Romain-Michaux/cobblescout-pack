# CobbleScout

Modpack Cobblemon (Fabric 1.21.1) entre amis, distribué avec [packwiz](https://packwiz.infra.link/).
L'instance Prism Launcher se met à jour toute seule à chaque lancement.

- Les mods et resource packs publics ne sont pas hébergés ici : ils sont téléchargés depuis Modrinth.
- `mods/cobblescout-*.jar` : mods maison.
- `mods/cobblemon-cards-*.jar` (MIT) et `mods/rustlingspots-*.jar` (MPL-2.0) : versions patchées pour
  afficher les noms de Pokémon en français. Les sources des modifications sont dans `sources/`.

Fichier généré par `preparer_pack.py` : ne pas modifier à la main.
